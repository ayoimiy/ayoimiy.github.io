## 这是什么

**Noita 知识库** 是一个个人维护的档案库，记录两件事：

1. 如何为 Noita 制作 Mod；
2. 如何把游戏机制拆成可验证、可复现的研究记录。

它面向的读者是愿意打开游戏目录、读 Lua、反复重启验证的人。这里不会把所有内容都写成“新手友好”的短句，但会尽量把失败路径和前置条件写清楚。

本站是非官方粉丝项目，与 **Nolla Games** 没有隶属关系。Noita 的名称、游戏内容与相关素材归其权利人所有。

## 内容原则

### 先记录，再解释

观察到现象，不等于理解原因。文章会尽量区分：

- **记录**：在什么版本、什么条件下看到了什么；
- **推测**：可能的原因，但还没有足够证据；
- **结论**：经过重复验证，并注明适用版本。

### 版本比日期重要

Noita 的机制和 Mod API 会变化。文章顶部的游戏版本、更新时间和测试条件，比“发布时间”更有参考价值。

### 不复制未经验证的配方

尤其是炼金、法术交互和 Mod 兼容性内容。没有条件的结果，不写成确定答案。

### 尊重来源与许可

引用社区 Wiki、他人代码或工具时尽量给出链接。不会在未经确认的情况下把游戏素材、他人 Mod 资源或整站内容当作自己的原创发布。

## 技术实现

| 部分 | 方案 |
| --- | --- |
| 站点框架 | Astro |
| 文档主题 | Starlight |
| 内容格式 | Markdown / MDX |
| 全文搜索 | Pagefind（构建时生成静态索引） |
| 部署 | GitHub Pages（每次推送自动构建发布） |
| 版本管理 | Git |

选择静态站点的原因很简单：内容为主、无需服务器、加载快，并且可以直接在 GitHub 上审阅每一次修改。
